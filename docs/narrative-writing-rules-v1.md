# Narrative 写作规则 v1

## Narrative 写什么

Narrative 写的是跨越多个完整材料以后，理解、关系、目标或方向怎样发生变化。

它不负责重新概括每条 Event，也不靠解释“这条 Arc 的意义”收尾。读者再次读到正文时，应从经历本身明白它为什么被留下。

## 先选写法

### 短跨度 / 单一经历

当材料仍围绕一次完整观看、一次争论、一次旅行、一次部署或一个清楚的小目标时，可以写细：

- 保留具体对话、发现和有实际影响的感受；
- 剧情讨论可以保留人物、伏笔、台词、歌曲意象、解析材料与观看顺序，但只有它们确实改变剧情理解时才进入正文；
- 不因篇幅短就抽象成主题总结。

OP、ED、PV 和外部解析若围绕同一剧情问题，直接写它们提供了什么线索，不解释为什么它们应被放在同一卷。

### 长跨度 / 多阶段变化

当材料横跨数周或数月，并经历多个方向或现实变化时，围绕一条变化轴重写：

- 保留关键日期和可重新落锚的原话；
- 多个 Events 若只是在重复施工，不逐条复述；
- 只在技术细节改变判断、造成失败或证明转折时写技术细节；
- 感受可以是兴奋、好奇、犹豫、失望、焦虑或平静，也可以没有明显情绪。只在它影响理解、行动、选择或落点时保留。

跨度长短不是固定天数。一次持续数周但因果完整的共同观看仍可细写；一天内经历多次方向翻转，也可能需要按变化线写。

## 材料取舍与事实收束

- 细节只有在帮助读者理解主线、转折、结果或当前状态时才进入正文；材料类型本身不是保留理由。
- 同一事实出现多个版本时，只写后续材料最终支持的版本，不复述猜错、被指出或重新核对的过程。若一次失败、回滚或改向本身改变了经历，它仍可作为实际发生的转折保留。
- 不按“事实、推测、纠正、未决问题”的固定模板写作。
- 不越过材料重新推测事实、剧情、动机或因果。原材料明确提出且未被后续材料否定的判断可以保留，但不得替它补出更完整的结论。
- 未完成状态只在材料中真实存在且影响当前理解或后续行动时保留；不逐项罗列所有可能性，也不为了结构完整制造悬念、问题、展望或答案。
- 叙事对象本身是正文中心。观看、讨论或施工的过程只有在它改变了后续判断、行动或结果时才写。
- 不解释为什么几份材料属于同一卷，也不总结这段经历证明了我们怎样、这条 Arc 有什么意义。
- 正文停在材料能够支持的最后一个状态、结果或选择，不另加诗性升华、认知变化总结或通用价值总结。

## 术语第一次出现

只有会妨碍读者理解当前经历的专属词或不常见术语，第一次出现时才在原句里用半句解释。能从上下文看懂的名称不必逐个翻译；如果删掉术语不影响叙事，优先删掉。

## 材料职责

- Event：证明一件事实际怎样发生。
- Scene：保存一段完整处境。
- Diary：保留当时第一人称的感受、理解与选择。
- Window Shadow：保存换窗门槛上的交接。
- Narrative：从以上材料中写出跨事件变化。

Narrative 可以引用 Event、Scene、Diary、Window Shadow 与补充材料，但不取得或复制它们的原文 ownership。

Diary 只在直接见证起点、转折或余波时加入。提到相同关键词、发生在同一天，或只是重复 Event 内容，都不是加入理由。Diary 保持整篇读取，不拆成 embedding 片段冒充独立经历。

## 发布前检查

1. 能否用一句话说出唯一的变化轴？
2. 删除 Event 编号后，正文是否仍像一段经历，而不是材料清单？
3. 关键日期、原话和失败是否仍能回到绑定材料？
4. 是否采用材料最终支持的版本，并避免复盘事实纠正过程或越过材料续推？
5. 是否出现“这条 Arc 记录了”“这说明我们”“我们没有把它当成……”等可以直接删除的元叙事？
6. 结尾是否自然停住，而不是为了升华又补了一段意义说明？
